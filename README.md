# 프로젝트 주제

Steam 게임 이용 이력과 메타데이터를 활용한 Hybrid 추천 시스템 및 Cold Start 문제 해결

* 사용자의 게임 상호작용 이력과 게임의 장르, 태그 데이터를 결합해 개인화된 게임을 추천하고, 사용자 또는 게임의 상호작용 데이터가 부족한 Cold Start 상황에서도 추천 성능을 유지할 수 있는지를 확인한다.

# 본 프로젝트의 핵심 과제

1. Hybrid 추천의 효과 : 사용자 상호작용 데이터와 게임 메타데이터를 결합하면 단일 추천 알고리즘보다 추천 성능이 개선되는가?

2. 사용자 Cold Start : 사용자의 상호작용 이력이 적을 때 Content-Based Filtering과 사용자 군집 정보를 활용하면 추천 성능 저하를 완화할 수 있는가?

3. 게임 Cold Start : 사용자 평가 이력이 부족한 신규 게임에 대해 메타데이터 기반 추천이 유효한 추천 결과를 제공할 수 있는가?

# 활용 데이터셋 및 데이터 역할

1) Steam Games Dataset (Kaggle)

- 게임 ID 및 게임명
- 장르
- 태그
- 카테고리
- 게임 설명
- 가격, 출시일, 평가 집계 등의 정보

활용 : Content-Based Filtering, 게임 유사도 계산, 신규 게임 추천

2) Game Recommendations on Steam (Kaggle)

- 사용자 ID
- 게임 ID
- 추천 여부
- 플레이 시간 관련 정보
- 리뷰 날짜
- 게임별 메타데이터 및 집계

활용 : Collaborative Filtering, Apriori, 사용자 취향 군집화, 추천 성능 평가

QnA -  본 데이터셋을 다음과 같이 활용해도 괜찮을까? 아니면 그냥 모두 두 데이터셋을 동일한 플로우의 알고리즘 구성에 각각 적용하여 비교해보는 방법은?

# 프로젝트 진행 순서

1. 데이터 분석 및 전처리 

두 데이터셋의 구조, 결측률, 게임 ID 일치율, 사용자별 리뷰 수 분포, 사용자-게임 행렬의 희소도를 확인한다.

2. 기본 추천 모델 구현

Popularity Baseline, Collaborative Filtering, Content-based Filtering을 각각 구현하고 기본 성능을 측정한다.

3. K-means 및 Apriori 구현

사용자 취향 군집을 생성하고, 전체 데이터 및 군집별 연관규칙(Association Rules)을 탐색한다.

4. Hybrid 모델 구성

CF와 Content-based 점수를 결합하고, K-means 및 Apriori의 결과를 추천 후보 생성이나 점수 보완에 반영한다.

5. Cold Start 실험

사용자 이력 수를 제한하고 신규 게임의 상호작용을 제거하여 각 모델의 성능을 비교한다.

6. 결과 분석 및 보고서 작성

추천 정확도, 순위 품질, Coverage, 실행 시간 등을 비교하고 각 알고리즘의 기여도와 한계를 정리한다.
